# Guía de uso

## Comandos principales

| Comando | Descripción |
|---------|-------------|
| `mkdocs serve` | Servidor local en tiempo real |
| `mkdocs build` | Genera el sitio estático |
| `mkdocs gh-deploy` | Publica en GitHub Pages |

## Instalación por sistema operativo

=== "Windows"
```bash
    pip install mkdocs mkdocs-material
```

=== "macOS / Linux"
```bash
    pip install mkdocs mkdocs-material
```

!!! warning "Requisito"
    Necesitas Python 3.8 o superior instalado.
